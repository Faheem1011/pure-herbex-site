## 2026-10-09 - Wrap Event Handlers in useCallback & Memoize ProductCard\n**Learning:** In a highly centralized React architecture (like App.tsx passing down handlers), using React.memo on leaf components (e.g. ProductCard) is useless unless all handler props (like onAddToCart, onQuickView) are wrapped in useCallback. Failing to do so creates new function instances on every App render, defeating memoization.\n**Action:** Always wrap handler props in useCallback when passing them to React.memo components.
